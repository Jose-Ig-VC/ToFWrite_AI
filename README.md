## ToFWrite AI - Plataforma de Reconocimiento Gestual Mediante Sensores ToF y Redes Neuronales Embebidas
El presente proyecto se desarrolla como proyecto final del curso de Introduccion a python, el cual propone una alternativa de ensenanza respecto a como se entrena un MLP para llegar al reconocimiento de gestos escritos, los cuales seran evaluados mediante puntos de posicion, obtenidos por el sensor VL53L0X, en lo que construimos, parecido a una pizarra.
